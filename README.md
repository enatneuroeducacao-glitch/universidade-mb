# Universidade MB

Portal estático de aprendizagem introdutória em óptica e atendimento, publicado por GitHub Pages.

## Conteúdo
- Leitura de receitas ópticas
- Lentes monofocais, bifocais e progressivas
- DNP, DP e centragem
- Atendimento consultivo
- Armações e materiais
- Limpeza e manutenção
- Ferramentas didáticas, avaliação geral, glossário e progresso local

## Publicação via GitHub Pages
1. No repositório, acesse **Settings → Pages**.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Selecione a branch `main` e a pasta `/ (root)`, depois salve.
4. Aguarde a publicação e use o endereço informado pelo GitHub Pages.

O arquivo principal é `index.html`; não há build, dependências, servidor ou banco de dados.

## Limitações da versão inicial
- Progresso salvo apenas no navegador atual via localStorage.
- Não há login, sincronização entre dispositivos, emissão de certificados nem painel de administração.
- Conteúdo educacional introdutório; não substitui prescrição, avaliação de profissional habilitado, instruções do fabricante ou formação regulamentada.
